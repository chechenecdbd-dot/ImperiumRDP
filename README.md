# ImperiumRDP

Инструмент удалённого администрирования для компьютерного клуба: живой экран (до 60 FPS,
аппаратный H.264 через NVENC), управление мышью/клавиатурой, процессы, командная строка,
передача файлов, буфер обмена, питание — всё из одной панели. Распространяется как
`ImperiumRDP.msi`, после установки — единое приложение **ImperiumRDP.exe** с двумя ролями.

Написан на C# / .NET 8; декодирование — через ffmpeg (входит в комплект).

```
ImperiumRDP.msi     — установщик (Program Files + ярлыки)
ImperiumRDP.exe     — хаб: «панель администратора» или «агент» на этом ПК
ImperiumRDP.Agent.exe   — агент (клубные ПК, TCP 48499, можно без GUI: --password/--install)
ImperiumRDP.Viewer.exe  — панель администратора (отдельным приложением)
ffmpeg.exe              — программный H.264-декодер для стороны администратора
```

## Возможности

| Функция | Описание |
|---|---|
| Экран в реальном времени | Основной монитор, захват через **DXGI Desktop Duplication**, кодирование **NVENC H.264** (аппаратное, до 60 FPS), CQP-качество на лету. Автоматический фолбэк на JPEG-тайлы, если NVENC/SingleGPU недоступен |
| Управление | Мышь (включая колесо и все кнопки), клавиатура скан-кодами (работают игры), текст — юникодом (любая раскладка, включая русскую в cmd) |
| Автоскан | Подсеть определяется автоматически, форматы: `192.168.1.0/24`, диапазоны, префиксы; список ПК запоминается, «Проверить список» — быстрый опрос сохранённых |
| Процессы | Список (PID/память/окно), завершение с деревом, запуск программ/URL/документов |
| CMD | Удалённая командная строка с потоковым выводом (кодировка OEM/866) |
| Файлы | Отправка на ПК (`%TEMP%` поддерживается), скачивание с ПК; надёжный канал — не теряются при нагрузке |
| Буфер обмена | Двунаправленный обмен текстом |
| Инфо | Имя, пользователь, ОС, CPU, память, аптайм, сеть, диски |
| Питание | Перезагрузка / выключение (с 15-сек отменой `shutdown /a`) / смена пользователя |
| Безопасность | Общий пароль → PBKDF2 (100 000 итераций) → взаимная аутентификация HMAC; весь трафик AES-256-CBC + HMAC-SHA256 (encrypt-then-MAC, защита от повторов) |

## Установка (MSI)

Мастер установки на русском спросит **роль этого компьютера**:

| Роль | Что делает |
|---|---|
| **Администраторский ПК** | Ярлык ImperiumRDP + открывает uplink-приёмник (TCP 48500) |
| **Игровой ПК клуба** | То же + **служба Windows «ImperiumRDP Agent Watcher»**: запускает агент скрыто в сеансе пользователя при каждом входе, следит и перезапускает. Брандмауэр настраивается автоматически |

**Подключение из дома при динамических IP клуба:**
1. На админском ПК панель показывает «Адрес для клубных ПК: your.ip:48500» (публичный IP определяется автоматически).
2. На клубных ПК при установке в поле «Адрес панели» впишите этот адрес (или позже — в хабе, поле «Адрес панели»).
3. Агенты клуба **сами подключаются** к вашей панели (исходящее соединение — провайдерские ограничения и NAT не мешают). Они появляются в списке панели автоматически, по имени, — IP клуба вообще не важен.

Динамические IP клуба больше не проблема: агент инициирует соединение сам и держит его, при обрыве — переподключается. Для сценария «в клубе тоже динамический IP у домашнего ПК» — используйте любой бесплатный DDNS (DuckDNS и т.п.) и пишите в поле адреса доменное имя.

Для клубных ПК без интерактивного выбора роли (GPO/скрипты):
`msiexec /i ImperiumRDP.msi ROLE=club UPLINK="домен.ру:48500" /qn`

Важно: захват экрана и управление работают, пока на клубном ПК кто-то залогинен (обычный режим
клуба — автологон). На экране входа Windows захват не передаётся — ограничение сессии, не бага.

## Сборка из исходников

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0), для MSI — WiX 5 с
UI-расширением (`dotnet tool install --global wix --version 5.0.2` и
`wix extension add -g WixToolset.UI.wixext/5.0.2`) и `ffmpeg.exe` в PATH.

```bat
build-installer.bat    :: publish + ImperiumRDP.msi
```

Быстрая отладочная сборка без MSI:

```bat
dotnet build ImperiumRDP.sln -c Release
:: агент:   src\ImperiumRDP.Agent\bin\Release\net8.0-windows\ImperiumRDP.Agent.exe
:: панель:  src\ImperiumRDP.Viewer\bin\Release\net8.0-windows\ImperiumRDP.Viewer.exe
:: хаб:     src\ImperiumRDP.GUI\bin\Release\net8.0-windows\ImperiumRDP.exe
```

Самопроверка конвейера (запущенный агент + `--password`):

```bat
dotnet run --project tests\SmokeTest -c Release
```

## Агент без GUI (для скриптов/GPO)

```bat
ImperiumRDP.Agent.exe --password ПАРОЛЬ     :: задать пароль (agent.json в ProgramData)
ImperiumRDP.Agent.exe --install             :: автозапуск (планировщик, скрыто, elevated)
ImperiumRDP.Agent.exe --uninstall
ImperiumRDP.Agent.exe --port N --fps N --quality N --hidden
```

Разрешение брандмауэра (один раз, от администратора):

```bat
netsh advfirewall firewall add rule name="ImperiumRDP Agent" dir=in action=allow protocol=TCP localport=48499
```

> Агент работает в сеансе пользователя (так и задумано — видеть/вести именно клубный рабочий стол).
> Для ввода в окна, запущенные «от администратора», и снятия системных процессов агент тоже должен
> работать с повышенными правами (`/RL HIGHEST` в `--install` уже это задаёт, при ручном запуске —
> «Запуск от имени администратора»).

## Панель администратора

1. Запустите `ImperiumRDP.Viewer.exe`, укажите пароль (Настройки) — один раз, сохранится в
   `%APPDATA%\ImperiumRDP\viewer.json`.
2. Подсеть подставится автоматически. «Сканировать» — найдёт все ПК с агентом, их видно с именем,
   пользователем и ОС. Список сохраняется, «Проверить список» — быстрый опрос сохранённых.
3. Двойной клик / «Подключиться» — сеанс: экран + панель инструментов (качество, FPS, буфер,
   файлы, процессы, CMD, инфо, питание, полноэкранный режим — Esc для выхода).

## Как подключаться из дома (клуб за NAT)

Прямое подключение из интернета «в клуб» без настройки не заработает — клубные ПК за роутером.
Варианты:

1. **VPN (рекомендуется, бесплатно).** Поставьте на один клубный ПК и на домашний:
   - [Tailscale](https://tailscale.com) — бесплатно до 100 устройств, ничего настраивать не надо, или
   - [ZeroTier](https://www.zerotier.com) — аналогично, или
   - WireGuard на любом белом IP/VPS — для гурманов.

   После этого на домашнем ПК клубная сеть видна как обычная подсеть (например 100.x.x.x/24) —
   вписываете её в поле сканера и работаете как по LAN. Весь трафик и так зашифрован нашим
   протоколом, VPN решает только задачу обхода NAT.
2. **Проброс порта на роутере клуба** (не рекомендуется): внешний порт → IP клубного ПК:48499.
   Работает, но каждый ПК = отдельный проброс, и порт «смотрит» в интернет.
3. **Готовые бесплатные альтернативы**, если хочется «поставить и забыть»: RustDesk (open-source,
   есть свой бесплатный self-host сервер), AnyDesk/TeamViewer free-версии. Собственный ImperiumRDP
   выгоден тем, что не зависит от чужих серверов и лимитов.

прежде чем добавлять зависимость, подумайте.

## Самопроверка (smoke-тест)

В репозитории есть сквозной тест: запустите агента, затем

```bat
dotnet run --project tests\SmokeTest -c Release
```

Он проверяет отказ по неверному паролю, рукопожатие, SysInfo, Ping-Pong, буфер обмена и поток тайлов.

## H.264-режим: требования и как он работает

- Захват: **DXGI Desktop Duplication** (GPU, без копирования через GDI); курсор рисуется
  программно из данных дублирования.
- Кодирование: **NVENC** (аппаратный H.264 любой NVIDIA GTX 900+): preset P4, tuning LowLatency,
  CQP, без B-кадров, IDR только по требованию (подключение нового зрителя / смена разрешения).
- Требования: NVIDIA-видеокарта + свежий драйвер, **один подключённый монитор** на машине агента
  (захватывается основной вывод с началом в 0,0). Если условий нет — агент автоматически работает
  в JPEG-режиме (все мониторы, GDI), панель переключается сама (признак в ScreenInfo).
- Декодирование (сторона администратора): **ffmpeg** из комплекта — процесс с pipe-входом/выходом,
  выдаёт готовые BGRA-кадры (`-probesize 32k -fflags nobuffer -flags low_delay` — задержка 2–3 кадра).
- FPS/качество меняются на лету из панели (FPS 2–144, quality → CQP 14–32).

## Про ring0 (ядро) — стоит ли?

Короткий ответ: **для этой задачи — нет, и вот почему.** Всё, что реально мог бы дать kernel-драйвер,
здесь решается в usermode дешевле и безопаснее:

| Что обещает ring0 | Решение без ядра |
|---|---|
| Ввод в окна с повышенными правами (обход UIPI) | Агент уже работает elevated (`--install` ставит `/RL HIGHEST`) — SendInput работает |
| Захват экрана UAC (secure desktop) | GPO клуба: UAC-запросы без затемнения/auto-elevate — административно и надёжно |
| Защита агента от любопытных посетителей | Обычные права у посетителей + ACL на папку агента — тот же эффект |
| Перезапуск агента-«смотрителя» | Планировщик заданий с перезапуском (уже есть) |
| Быстрый захват | DXGI Desktop Duplication + аппаратный H.264 — это GPU-путь, ядру там делать нечего |

Аргументы против ядра именно в клубе:

1. **Античиты.** На клубных ПК крутятся EAC/BattlEye/Vanguard. Неизвестный kernel-драйвер +
   античит = баны клиентов и репутация клуба.
2. **Подпись драйверов.** Без тестового режима (testsigning) драйвер не загрузится; тестовый режим
   сам по себе конфликтует с античитами и VBS/HVCI. Продуктовая подпись — EV-сертификат + WHQL.
3. **BSOD = простой клуба.** Любой баг в драйвере — синий экран на машине, которая должна зарабатывать.

Реальный следующий шаг по производительности — usermode: **DXGI Desktop Duplication (захват с GPU)
+ H.264 через Media Foundation (аппаратные кодеки клубных видеокарт)** — это даст 5–10× экономию
канала против JPEG-тайлов при том же качестве. Звука, полного UAC и Ctrl+Alt+Del это не добавит,
но их и не нужно.

## Ограничения (осознанные)

- **Ctrl+Alt+Del** нельзя передать — защищённый стол Windows. Пуск → «Изменить пароль» и т.п. недоступны.
- **Alt+Tab** перехватывается локальной Windows до окна панели; на удалённом ПК используйте
  панель задач/клавиши через меню приложений, либо локальный Alt+Tab сворачивается — сверните окно.
- **Экран UAC** (запрос «Да/Нет» от администратора) — secure desktop, не захватывается и не
  принимается ввод; подтвердите запрос локально (или отключите UAC- prompt на клубных ПК,
  что в клубах обычно и так сделано).
- Экран блокировки Windows: захват может быть пустым до входа пользователя.
- Звук не передаётся.
- Пароль хранится в `agent.json` открытым текстом — ограничьте доступ к папке на клубных ПК
  (пользователи клуба работают под обычными правами и не читают `C:\ImperiumRDP` при раздаче
  прав «только администраторы»).

## Что где лежит после установки

```
C:\Program Files\ImperiumRDP\          — ImperiumRDP.exe (хаб), Agent, Viewer, Service, ffmpeg.exe
C:\ProgramData\ImperiumRDP\            — agent.json (пароль/порт), agent.log, service.log
%APPDATA%\ImperiumRDP\viewer.json      — настройки панели (пароль зашифрован DPAPI)
Ярлыки: общий рабочий стол + меню «Пуск» → ImperiumRDP
Служба (роль «клуб»): «ImperiumRDP Agent Watcher», автозапуск
```

## Структура протокола (коротко)

```
TCP → [4 байта длины BE][1 байт тип][данные]
рукопожатие: Hello(соль, вызов) → ClientAuth(HMAC-доказательство) → ServerAuth(HMAC-доказательство)
после аутентификации: данные = AES-CBC(IV случайный) + HMAC-SHA256(seq, тип, IV, шифртекст)
видео: TileBatch{метаданные экрана, тайлы 64×64 JPEG}, ключевой кадр каждые 3 с / по запросу
```
